# OctoAcme Project Management Docs

This directory is the index for OctoAcme's project management processes. The
approach is customer-first and iterative, with clear ownership, data-informed
decisions, and psychological safety for learning and feedback.

## Process at a glance

Projects move through **initiation**, **planning**, **execution**, **release**,
and **retrospective/continuous improvement**. Teams use project boards,
prioritized backlogs, acceptance criteria, a Definition of Done, release
plans, and risk registers to keep work actionable and transparent.

The core personas are the **Project Manager**, **Product Manager**, developers,
QA/testing, and stakeholders. The PM coordinates delivery, risks, and
communication; the Product Manager owns outcomes and prioritization; delivery
roles build and validate the work; and stakeholders provide input and approval.

Communication includes PM/Product Manager syncs, delivery standups, demos,
stakeholder updates, status templates, and defined escalation paths. Quality
assurance combines unit and integration tests, end-to-end smoke tests,
security scanning, CI checks, and manual QA when needed.
